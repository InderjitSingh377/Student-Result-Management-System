## Student-Result-Management-System
This project focuses on developing a Student Result Management System (SRMS). Its core function is to securely manage and process academic performance data, including the input of subject marks and the automatic calculation of grades, averages, and overall performance metrics. The SRMS is designed to automate the generation of digital report cards, 
reduce manual errors, and provide a transparent, accessible platform for students, parents, and faculty to view and monitor academic progress instantly.
